# Release Documentation

This folder stores versioned release notes for PulseWard.

## Current release

- 1.2.0

## Rules

1. Every version bump in package.json requires a release note file.
2. Release notes must include API changes, integration changes, and operational impact.
3. Include migration and rollback notes for any non-trivial change.

# PulseWard Hospital Management System - Patient Portal

Welcome to the **PulseWard** Patient Portal! This application is designed to empower patients by providing easy access to their health information and enabling them to manage their appointments effectively.

## Project Overview

The **PulseWard** Hospital Management System (HMS) is a comprehensive solution aimed at streamlining hospital operations and enhancing patient care. The Patient Portal is one of the key applications within this system, allowing patients to interact with their healthcare providers seamlessly.

## Features

- **User Authentication**: Secure login and registration for patients.
- **Health Records Access**: View and manage personal health records.
- **Appointment Management**: Schedule, reschedule, or cancel appointments with healthcare providers.
- **Notifications**: Receive reminders and updates regarding appointments and health information.
- **User-Friendly Interface**: Intuitive design for easy navigation and accessibility.

## Development Model

This project follows an **iterative development model**, allowing for continuous feedback and improvement. Each iteration focuses on delivering specific features and enhancements based on user needs and testing results.

## Getting Started

To set up the Patient Portal locally, follow these steps:

1. Clone the repository:

   ```
   git clone https://github.com/Life-Experimentalist/PulseWard-HMS.git
   ```

2. Navigate to the Patient Portal directory:

   ```
   cd PulseWard-HMS/apps/patient-portal
   ```

3. Install dependencies:

   ```
   npm install
   ```

4. Start the application:
   ```
   npm start
   ```

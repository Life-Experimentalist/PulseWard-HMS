# PulseWard UI Kit

Welcome to the **PulseWard UI Kit**! This package contains a collection of reusable UI components designed to streamline the development of applications within the PulseWard Hospital Management System. The UI Kit aims to provide a consistent look and feel across all applications, enhancing user experience and reducing development time.

## Features

- **Reusable Components**: A set of pre-built UI components that can be easily integrated into various applications.
- **Customizable Styles**: Components come with customizable styles to fit the branding of the PulseWard system.
- **Accessibility**: All components are designed with accessibility in mind, ensuring that they are usable by everyone.
- **Responsive Design**: Components are built to be responsive, providing a seamless experience across devices.

## Installation

To install the UI Kit, use the following command:

```bash
npm install @pulseward/ui-kit
```

## Usage

Import the components you need in your application:

```javascript
import { Button, Card } from "@pulseward/ui-kit";
```

### Example

Here’s a simple example of how to use the Button component:

```javascript
<Button onClick={handleClick} variant="primary">
  Click Me
</Button>
```

# PulseWard Release 1.1.0

Release date: 2026-04-01

## Summary

This release adds modular integration options with free-first defaults, Apple Calendar support, executable provider test routes, and a polished landing page demo.

## Highlights

- Added provider routing foundation for messaging and calendar channels.
- Added free-first providers (Telegram, Email SMTP, Webhook) and optional paid WhatsApp.
- Added Apple Calendar provider option.
- Added executable APIs for listing and testing providers.
- Added tenant integration config schema and validation flow.
- Added landing page demo with dashboard previews.

## API Contract Updates

- Notification service OpenAPI updated to 1.1.0.
- Appointment service OpenAPI updated to 1.1.0.
- New integration provider fields include billing metadata and admin setup guidance.

## Operational Impact

- Hospital admins now own provider onboarding and billing completion for paid channels.
- Integration configuration remains per-tenant and auditable.

## Migration Notes

1. Add INTEGRATION_EMAIL_SMTP_CREDENTIALS and INTEGRATION_APPLE_CALENDAR_CREDENTIALS env references.
2. Update tenant integration config files to include billing metadata and free-first routing.
3. Validate configs using node scripts/validate-integration-config.mjs.

## Rollback Plan

- Revert to previous tenant integration config versions.
- Keep WhatsApp and Outlook providers disabled if admin setup is incomplete.
- Route through free fallback providers (Telegram, Email, Webhook, ICS).

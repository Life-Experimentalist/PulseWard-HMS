## Weekly Backup Verification Checklist

This is an automated operational checklist issue.

### Scope

- Verify backup success for all active hospital tenants.
- Verify restore test for one randomly selected tenant.
- Verify retention policy and encryption compliance.

### Checklist

- [ ] Confirm latest database backup exists for each tenant
- [ ] Confirm object storage snapshot completed
- [ ] Confirm backup encryption status
- [ ] Perform one restore validation in non-production
- [ ] Record RPO and RTO measurements
- [ ] Document anomalies and remediation actions
- [ ] Link any follow-up incident/risk issues

### Notes

Add evidence links (logs, dashboards, restore output) before closing.

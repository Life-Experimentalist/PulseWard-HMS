Get Started in 5 Minutes

One Command Deploy

The entire stack — API, 4 frontends, nginx, SQLite — starts with a single command.

$ docker compose up -d
Full setup walkthrough (5 steps)
  1. 1

    Prerequisites

    Install Docker Desktop and Git. Node 24+ required for local dev only.

  2. 2

    Clone the repository

    git clone https://github.com/Life-Experimentalist/PulseWard-HMS.git
cd PulseWard-HMS
  3. 3

    Configure environment

    cp .env.example .env
node scripts/generate-jwt-secret.mjs

    Copy the environment template, then edit .env and set JWT_SECRET to the value the generator prints. Everything else works with the defaults.

  4. 4

    Start the stack

    docker compose up -d

    Starts the API Gateway (internal :8787) and an nginx reverse proxy on :80/:443 serving all four portals as static files. Want hot reload for local development instead? Run pnpm run dev.

  5. 5

    Open your portals

    In the Docker stack, nginx serves each portal on the hostname you set in nginx/nginx.conf (portal., clinician., admin., ops.). Running pnpm run dev serves them directly at:

    Patient Portal:4313 Clinician Portal:4311 Admin Console:4180 Ops Dashboard:4312

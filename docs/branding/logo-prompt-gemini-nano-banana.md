# Gemini Nano Banana Prompt for PulseWard Logo

Use this prompt in Gemini Nano Banana to generate a subtle, professional logo system.

## Prompt

Design a premium but subtle brand identity for "PulseWard", a hospital operations and care management platform.

Requirements:

- Style: modern healthcare, trustworthy, calm, minimal, not playful
- Mood: clinical clarity with human warmth
- Logo mark: abstract pulse + shield + care flow concept
- Wordmark: PulseWard
- Color direction: deep teal primary, slate neutral, warm accent (avoid neon)
- Must look good on white and dark surfaces
- Deliverables:
  1. Primary logo horizontal
  2. Stacked logo
  3. Icon-only mark
  4. Favicon variant
  5. Monochrome versions
- Export guidance: SVG-first, plus PNG at 1024, 512, 256, 128
- Accessibility: maintain strong contrast and legibility at small sizes
- Avoid medical cliches like literal red crosses
- Avoid generic AI gradient styles

Also provide:

- Suggested typography pairing for headings and body
- Brand token suggestions: primary, secondary, accent, surface, text
- Brief rationale in 5 bullet points

## Variant Prompt (Hospital Customizable Family)

Create a configurable logo family system where base brand is PulseWard and each hospital tenant can add a subtle submark text (for example: "PulseWard | CityCare Hospital") without redesigning the core icon.

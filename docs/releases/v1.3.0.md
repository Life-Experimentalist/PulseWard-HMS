# PulseWard Release 1.3.0

Status: Stable milestone rebaseline release

## Summary

Release 1.3.0 resolves milestone accounting drift, synchronizes package version metadata across root and app manifests, and ships a Docker Desktop-first setup path to make local testing predictable for non-DevOps users.

## Highlights

- M6 contract-hardening ledger checkpoint:
  - Contract-hardening stream is documented through M6.228.
  - Roadmap estimate drift is corrected with explicit status notes so slice counts and milestone status are no longer ambiguous.
- M7.1 operability seed:
  - New one-command setup path with Docker Desktop checks and guided output.
  - Deployment quickstart now includes a decision-tree style flow and concrete port validation steps.
- Version consistency:
  - Root package version is now 1.3.0.
  - Web app package versions are now aligned to 1.3.0.
  - Lockfile root metadata is aligned to the same version values.
- Documentation refresh:
  - Docs status pages now reflect current milestone reality (M6 contract stream complete, M6 milestone still in progress pending exit criteria).
  - Release index and versioning policy now point to 1.3.0.

## API And Contracts

- API base path remains /api/v1.
- Existing OpenAPI service versions remain service-scoped and unchanged in this release.
- No backward-incompatible API contract changes are introduced by this release.

## Operational Impact

- Faster and safer local onboarding for operators using Docker Desktop.
- Reduced confusion in roadmap progress tracking and release-state interpretation.
- More predictable CI and local artifact alignment through synchronized version metadata.

## Migration Notes

1. Pull latest changes.
2. Run npm ci.
3. Run npm run setup:demo.
4. Validate stack with docker compose ps.

## Rollback Notes

- Revert this release commit to return package metadata and docs to the previous state.
- If local stack issues occur after upgrade, run npm run demo:down, then rerun npm run setup:demo.

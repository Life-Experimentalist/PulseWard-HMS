# PulseWard Clinician Portal

Welcome to the **PulseWard Clinician Portal**! This application is part of the PulseWard Hospital Management System (HMS) designed to empower clinicians with the tools they need to manage patient care efficiently.

## Project Overview

The Clinician Portal provides clinicians with access to patient records, appointment management, and clinical decision support tools. It is designed to streamline workflows and enhance the quality of care provided to patients.

## Features

- **Patient Management**: View and manage patient records, including medical history, medications, and allergies.
- **Appointment Scheduling**: Schedule, reschedule, and cancel patient appointments with ease.
- **Clinical Decision Support**: Access tools and resources to assist in clinical decision-making.
- **Secure Messaging**: Communicate securely with other healthcare professionals and staff.
- **Reporting**: Generate reports on patient care and clinical outcomes.

## Technology Stack

- **Frontend**: React.js for building user interfaces.
- **Backend**: Node.js and Express for handling API requests.
- **Database**: MongoDB for storing patient records and application data.
- **Authentication**: JWT (JSON Web Tokens) for secure user authentication.

## Development Setup

To set up the development environment, follow these steps:

1. Clone the repository:

   ```bash
   git clone https://github.com/Life-Experimentalist/PulseWard-HMS.git
   cd PulseWard-HMS/apps/clinician-portal
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm start
   ```

4. Access the application at `http://localhost:3000`.
